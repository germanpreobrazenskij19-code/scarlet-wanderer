# Сайт Scarlet Wanderer

Простой сайт игры без JavaScript: `index.html` (102 строки) и `css/style.css` (164 строки). Все движения сделаны CSS-анимациями.

```
index.html       разметка страницы
css/style.css    оформление
img/             картинки: фон, мох, герой, мотылёк, дождь, скриншот, иконки
```

## Как устроена страница

1. **Главный экран** (`<header class="hero">`)
   - Фон — картинка `<img class="hero-bg">`. Свойство `object-fit: cover` растягивает её на весь экран без искажений.
   - Дождь — блок `<div class="rain">` с прозрачной картинкой капель. CSS-анимация `@keyframes rain` двигает её вниз.
   - Название из двух `<span>`. По умолчанию `span` строчный, поэтому `display: block` ставит слова друг под другом. Так «Scarlet» и «Wanderer» можно оформить по-разному.
   - В слогане `<br>` переносит строку, а `<span class="red">` красит одно слово.
   - Земля — картинка мха `<img class="ground">`, прижатая к низу экрана.
   - Герой — блок `.player` с двумя картинками: `hero.svg` (герой) и `moth.svg` (мотылёк).

2. **Об игре** — текст с `<span>` и `<br>`, ссылка на Steam с иконкой `<img>`.
3. **Галерея** — сетка `display: grid` со скриншотами `<img>`. Клик открывает картинку в полном размере.
4. **Сообщество** — ссылка на Discord и иконки соцсетей (`<img>` внутри `<a>`).
5. **Подвал** — почта и копирайт, между ними `<br>`.

## Как герой ходит без JavaScript (всё в `css/style.css`)

- `@keyframes patrol` меняет у `.player` свойство `left`: за 20 секунд герой доходит до правого края (82%) и возвращается к левому (8%).
- `@keyframes turn` в середине пути переворачивает картинку героя через `transform: scaleX(-1)`. Длительность та же, 20 секунд, поэтому разворот совпадает с краем пути.
- `@keyframes step` чуть поднимает героя (`margin-bottom`) каждые 0,3 секунды, и получается покачивание при шаге.
- `@keyframes follow` в момент разворота переносит мотылька на другую сторону, чтобы он всегда летел позади героя. `@keyframes fly` плавно качает его вверх-вниз.
- Крылья мотылька и моргание героя — анимации внутри самих файлов `moth.svg` и `hero.svg`.

## Что заменить

Места помечены в `index.html` комментарием `ЗАМЕНИТЬ`: описание игры, ссылка на Steam, Discord, соцсети и почта.
Чтобы добавить скриншот, положите его в `img/` и скопируйте строку с `<img>` в галерее.

## Запуск

- Локально: откройте папку в VS Code и запустите расширение **Live Server** (кнопка Go Live).
- Выложить на Vercel: `npx vercel deploy --prod` из папки проекта.
