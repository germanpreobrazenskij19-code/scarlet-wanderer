# Сайт Scarlet Wanderer

Мой сайт про игру Scarlet Wanderer. JavaScript не используется, всё на HTML и CSS.

Кнопки и карточки взял с сайта бутстрапа (getbootstrap.com), остальное писал сам.

```
index.html       разметка страницы
css/styles.css   оформление
img/             картинки: кадр из игры, скриншоты, спрайты мотылька и жука, иконки
```

## Что на странице

1. Главный экран — кадр из игры на весь экран, сверху название и кнопка вишлиста.
2. Об игре — текст про странника, фон — картинка леса затемнённая.
3. Вишлист в Steam — большой блок с иконкой.
4. Галерея — три карточки бутстрапа: скриншот и два спрайта из игры (мотылёк и жук).
5. Сообщество — Discord и соцсети.
6. Подвал — почта и копирайт.

Просто открыть index.html в браузере. Или запустить в папке `python3 -m http.server` и зайти на `localhost:8000`.
